# Project Memory

This is Alex's personal portfolio website, designed for GitHub Pages.

## Positioning

- The site should present two main dimensions:
  - AI Work / Vibe Coding: tools, workflow experiments, interface prototypes, and GitHub projects.
  - Photography: an independent creative practice and portfolio, not a forced metaphor for work.
- Photography should show taste, attention, long-term commitment, and execution quality. Do not frame it as a direct recruiting or AI-work skill unless Alex explicitly asks.
- Recruiting Any is an important featured experiment, but not the whole identity of the site. Leave room for future projects.

## Design Direction

- Keep the camera/viewfinder interaction as the signature homepage experience.
- Use Alex's own photos as visual material. Do not generate new images unless Alex explicitly changes this direction.
- Maintain a refined portfolio feel: simple, cinematic, tactile, watercolor/oil-painting influenced, but not decorative or cluttered.
- Transitions should feel creative and interactive, especially focus, shutter, playback, and photo-review moments.

## Content Structure

- Preferred top-level structure:
  - Home
  - Work
  - Photography
  - About
- Work combines AI Work and Vibe Coding into one section.
- Work can include:
  - Featured experiment: Recruiting Any
  - More experiments
  - Process notes
- Photography should feel like a real photography portfolio with minimal explanatory text.

## Coding Reference

- Use the installed `andrej-karpathy-skill` as a coding behavior reference when writing, reviewing, debugging, or refactoring code in this project.
- Keep changes simple, focused, and verifiable.
- Avoid overbuilding future features before Alex asks for them.
- Preserve existing visual direction and interaction language unless the request changes it.
